发布前看什么

  1. 只选择任务确实需要的 REST 操作或 MCP 工具。
  2. 核对输入输出、读写影响、重试与审批规则。
  3. 把地址和凭据留在连接配置，清单只写环境变量名。
  4. 发布后检查能力列表，再明确启用版本。
