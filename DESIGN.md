# Web integration design

The chat extends the existing admin interface: teal `#116b64`, ink `#18313b`, muted `#51636a`, white panels and warm ground `#f4f6f3`. Use system typography, clear keyboard focus and modest borders. The host owns placement, theme overrides and lifecycle.

This is an Operate surface: one composer submits tasks or required input. Each turn shows status, a stop action, exact approval arguments and a final answer. Unconfirmed results remain visibly distinct. Long answers and argument blocks scroll within the panel; model content is text, never executable HTML.

Desktop acceptance covers the embedded panel and resized desktop layouts. The demonstration labels its data and deterministic model. No external fonts, visual assets or UI runtime dependency is required.
